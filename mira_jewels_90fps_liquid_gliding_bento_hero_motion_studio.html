90fps Lockstep Push-Displacement Spec & Code

Every appearing tile physically pushes back the present ring tile along a shared locked boundary (zero overlap)

How True Edge-to-Edge Push Displacement Works (Zero Overlap):
  • Entry-Edge Pre-Staging: Before an appearing tile enters from the top, bottom, or right edge, it is pre-staged flush against the outer border (e.g., top: -42.5%, height: 40.5% or left: 101.7%, width: 84.8%) with transition: none.
  • Synchronized Shared Boundary: On the next animation frame, both the appearing tile and the present ring tile animate with 0ms relative delay and identical cubic-bezier(0.22, 1, 0.36, 1) easing. Because Appearing_Edge(t) + Gap === Present_Ring_Edge(t) for all t ∈ [0, 1], the appearing tile physically pushes and compresses the ring tile back instead of overlapping it.
/* Lockstep Push Displacement Rule:
   Appearing tile and present ring tile share an exact moving boundary:
   Right-to-Left Push: appearing.left(t) - present.right(t) = 1.7% (constant gap)
   Top-to-Bottom Push: present.top(t) - appearing.bottom(t) = 2.5% (constant gap) */
function pushTransition(stage, fromState, toState) {
  // 1. Pre-stage newly entering tiles flush against the entry edge with no transition
  enteringTiles.forEach(tile => {
    tile.classList.add('no-transition');
    setRect(tile, fromState[tile.id]);
  });
  stage.offsetHeight; // Force reflow

  // 2. Animate both appearing and pushed tiles in lockstep (0ms delay difference)
  allTiles.forEach(tile => {
    tile.classList.remove('no-transition');
    tile.style.transitionDelay = '0ms';
    setRect(tile, toState[tile.id]);
  });
}
